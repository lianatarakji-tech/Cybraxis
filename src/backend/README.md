# Cybraxis Backend Scaffold

This folder contains backend-facing contracts and mock API functions.

At this stage, it is not a real server.

The purpose is to prepare the project for persistence and backend migration without disrupting the working React simulator.

## Folders

- `models/` defines data object shapes.
- `api/` contains mock backend-like functions.

## Current Status

Phase 1: local contracts and mock APIs.

## Future Status

These files can later be replaced or connected to:

- Express
- Firebase
- Supabase
- MongoDB
- PostgreSQL
- AI mentor backend service
